# QMS 年度內部稽核系統

114 年度內部稽核查檢表完整種子（九潤精密／正隆興精密），對應 QR-28 系列紙本表單設計。

## 快速開始

```bash
npm install
npm run dev    # http://127.0.0.1:43123
npm test       # 84 項單元／回歸／smoke 測試
npm run build  # production bundle → dist/
npm run preview -- --port 43124 --host 127.0.0.1
```

## 升級與資料遷移（v6）

1. 取得最新版（含年度資料集、獨立事件、人員資格與觀察台帳）
2. 建議先在「系統設定」表單 **備份** 現有資料（完整 AppState JSON）
3. localStorage key：`qms-annual-internal-audit-v6`（會自動自 v5 / v4 / v1 遷移）
4. 若仍白屏：系統設定 → **清除全部資料**，或 DevTools 刪除舊 key 後重新整理
5. 驗證：`npm run lint && npm test && npm run build` 全過、十二個表單皆可瀏覽

v5 文字姓名會完整保留為「既有姓名／待配對」，不會因同名、自訂字串或職稱自動取得合格資格。較新的未知資料版本會拒絕降版還原。

## 十二個表單與 ISO 9001 稽核工作流

左側導覽以「受控準則與程序 → 稽核方案管理 → 資源與準備 → 稽核活動執行 → 稽核結果與改善」排序。這是將 ISO 9001 內部稽核要求轉成可執行工作流的介面設計，不把條文誤當成唯一固定畫面；稽核方案與稽核活動的階段參考 ISO 19011 的管理與執行架構。

1. **稽核總覽**：年度進度、待判定、未結 NCR 與開始前人員資格待處理。
2. **標準**：公司／廠區適用標準、版本、證書範圍與依據。
3. **程序**：確認稽核程序代碼、版本、正式紀錄保存位置，以及查檢表種子來源與覆蓋範圍；這頁是受控來源與追溯控制，不是另一份稽核結果表。
4. **年度稽核計畫**：同一份表單完成年度、計畫窗口、主任稽核員、外部稽核／管理審查日期、利害關係人與程序月格編排，並可預覽、套用及匯出。
5. **方案風險與優先順序**：涵蓋全部 QP 的七因素稽核優先順序，分開記錄上次內稽與第三方稽核 NCR、客訴等；未知因素標示暫定，不把公司算法宣稱為標準要求。
6. **稽核員能力與任命**：人員主檔、跨公司關係、多角色資格／任命、年度陪稽、Excel 與列印。
7. **稽核啟動與活動準備**：雙公司證據、第三方團隊與年度陪稽安排。
8. **稽核執行與證據**：同一 QP／單位可建立多次獨立事件；開始前檢查實際日期、標準、程序版本、資格範圍及客觀性，並保存團隊快照。
9. **不符合與矯正措施**：保存來源事件、要求／證據／發現快照；結案須有矯正措施與效果確認紀錄。
10. **觀察事項與追蹤**：管理內稽／第三方來源與事件、歷年篩選、逐次追蹤與修訂歷程、跨年帶入、結案證據及轉 NCR 關聯。
11. **改善機會與建議**：第三方建議與跨年追蹤，語意與 NCR 分開。
12. **系統設定**：評分、備份／還原、匯出及危險操作；年度計畫、標準與程序資料不在此重複維護。

系統資料架構採「受控來源主檔 → 年度工作資料集 → 稽核事件歷史紀錄」三層分離。每年切換時，系統封存目前年度的設定、計畫、稽核事件、NCR、觀察事項與稽核前準備；新年度建立自己的工作資料，舊年度仍可切回。標準／程序或查檢表來源可以改版，但稽核開始時會固定保存適用標準、程序代碼／版本、正式紀錄保存位置與稽核團隊快照；稽核回報後查檢內容鎖定，NCR、觀察事項與跨年追蹤保留來源事件及查檢項目關聯。

左側系統名稱是桌面首頁按鈕；窄螢幕頂部另有明確「首頁」按鈕。

## 採用的紙本設計優點

1. **程序導向** — 以 QP 查檢表為主；QP-16 業務部/品保部獨立項目  
2. **QR-28-02 表頭** — 被稽核部門、稽核流程、對應文件、日期、主管、稽核人員  
3. **列格式** — 項目｜NO｜稽核內容｜判定｜內容說明  
4. **稽核重點標示** — 儀表板 focusLegend（風險、單位、負責人、項數）  
5. **月格計畫** — 擬定/滿意/不滿意/矯正中/矯正圓滿  
6. **雙公司** — 九潤精密｜正隆興精密  
7. **三類稽核** — 系統｜製程(QR-28-04)｜型態(QR-28-05)  
8. **跨年度** — 年度資料集保存，NCR/觀察/第三方建議以來源關聯帶入新年度
9. **建議追蹤** — open/closed 一覽表  
10. **稽核前準備** — 雙公司合併取證外部稽核前查核表（一張證書、兩家公司）  
11. **人員資格** — 內部／第三方角色分開，陪稽人員不視為稽核判定人員
12. **列印 CSS** — QR-28 表單邊框版型

## 外部稽核前準備（dual_company_single_certificate）

- 種子：`src/data/externalAuditPrep.seed.json`  
- 來源：**第三方主任稽核員長期觀察 — 九潤+正隆興合併稽核取得一張證書**（措辭 verbatim，不自行改寫）  
- 欄位：項次｜稽核前準備事項｜負責人｜九潤｜正隆興｜完成｜備註/表單  
- 範圍模式：`both_separate`（◎◎）、`merged`（合併）、`site_scope`（稽核廠區範圍）  
- 序位橫幅：內部稽核完成 → 管理審查完成 → 外部稽核；未結 NCR / 管審順序錯誤時警告  
- 狀態依年度共用，儲存於 AppState `externalAuditPrep`（非 per-company）

## 資料

- 查檢表種子：`src/data/checklists.seed.json`（`import.finalized: true`）  
- localStorage：`qms-annual-internal-audit-v6`（自動自 v5 / v4 / v1 遷移）

## 備份與還原

- **系統設定 → 備份**：下載含雙公司、設定、`externalAuditPrep`、版本號的 JSON（`QMS備份_YYYY-MM-DD.json`）
- **系統設定 → 還原**：選擇備份檔，確認覆寫後寫入 localStorage v6；v5/v4/v1 舊檔會自動遷移
- 還原前建議先備份；失敗時不會覆寫（需通過結構驗證）

## QR-28 表單匯出

| 表單 | 位置 | 格式 |
|------|------|------|
| QR-28-01 年度計畫 | 年度稽核計畫 / 系統設定 | Excel、HTML（Word 可開） |
| QR-28-02 程序查檢表 | 稽核執行與證據 / 程序（全部） / 系統設定 | Excel（目前／全部）、HTML |
| QR-28-03 不符合 | 不符合與矯正措施 | Excel |
| QR-02-01 方案風險 | 方案風險與優先順序 / 系統設定「匯出全部表單」 | Excel |
| 適用標準 | 標準 | Excel |
| 觀察台帳 | 觀察事項與追蹤 / 系統設定「匯出全部表單」 | Excel |
| 建議追蹤 | 改善機會與建議 / 系統設定「匯出全部表單」 | Excel |
| 稽核前準備 | 稽核啟動與活動準備 / 系統設定「匯出全部表單」 | Excel |
| 人員合格名單 | 稽核員能力與任命 | Excel、列印 |

瀏覽器端由專案內建的最小 OOXML 產生器建立 `.xlsx`，不依賴 SheetJS；欄位對齊現有 UI／紙本表頭。列印 PDF 可用各 tab「列印」或瀏覽器「另存 PDF」。
