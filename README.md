# QMS 年度內部稽核系統

114 年度內部稽核查檢表完整種子（九潤精密／正隆興精密），對應 QR-28 系列紙本表單設計。

## 快速開始

```bash
npm install
npm run dev    # http://127.0.0.1:43123
npm test       # 執行目前的單元測試
```

## 採用的紙本設計優點

1. **程序導向** — 以 QP 查檢表為主；QP-16 業務部/品保部獨立項目
2. **QR-28-02 表頭** — 被稽核部門、稽核流程、共用受稽核程序文件快照、日期、主管、稽核人員
3. **列格式** — 項目｜NO｜稽核內容｜判定｜內容說明
4. **稽核重點標示** — 年度計畫 focusLegend（風險、單位、負責人、項數）；儀表板不重複
5. **月格排程** — 年度計畫月格只切換空白／擬定（手動排程）；滿意、不滿意、矯正中、矯正圓滿等結果由查檢與 NCR 推導顯示（`src/lib/planStatus.ts`），不寫入 `months`
6. **雙公司** — 同一場稽核使用一份年度計畫、共同時程、人員及受稽核程序文件；計畫列可標示適用兩家公司或單一公司。新建查檢表從共用計畫帶入表頭，已建立表單保留當時文件、人員與題目快照。公司別月格排程、查檢判定、逐題佐證紀錄引用、NCR、觀察及建議各自保存。兩家公司可引用同一份佐證，也可各填獨立紀錄；只有同程序、同部門且題目快照一致時，畫面才提供明確的「套用此引用」操作，判定不會跟著複製。
7. **查檢生命週期** — 規劃中 → 開始稽核 → 執行中（僅此狀態可判定）→ 完成回報 → 已回報（鎖定）。符合／不符須客觀證據、不適用須理由，缺項不算已評。
8. **年度與任命** — 內稽年度僅在頁首切換；主任稽核員讀人員合格名單有效任命（`settings.leadAuditor` 僅舊資料相容，列印匯出可能仍讀取）。外稽日期僅在外稽準備編輯並同步 `settings.externalAuditDate`。
9. **儀表板觀察計數** — 三數分開：本年查檢觀察（判定次數）、本年度待追蹤（台帳 open 且年度＝今年）、前年度未結（open 含封存）。待改善追蹤可深連結 `#tab=…&record=…` 開到該筆並展開。
10. **三類稽核** — 系統｜製程(QR-28-04)｜型態(QR-28-05)
11. **跨年度** — NCR/觀察/第三方建議帶入新年度
12. **建議追蹤** — open/closed 一覽表
13. **稽核前準備** — 雙公司合併取證外部稽核前查核表（一張證書、兩家公司）；內部稽核完成為兩證覆蓋推導唯讀，不可手動勾成完成
14. **列印 CSS** — QR-28 表單邊框版型

## 外部稽核前準備（dual_company_single_certificate）

- 種子：`src/data/externalAuditPrep.seed.json`
- 來源：**第三方主任稽核員長期觀察 — 九潤+正隆興合併稽核取得一張證書**（措辭 verbatim，不自行改寫）
- 欄位：項次｜稽核前準備事項｜負責人｜九潤｜正隆興｜完成｜備註/表單
- 範圍模式：`both_separate`（◎◎）、`merged`（合併）、`site_scope`（稽核廠區範圍）；第 2、19 項須同時確認共用彙整與兩家公司來源紀錄，廠區項目須填實際範圍才計入完成。
- 序位橫幅：依第 2、4 項分別顯示兩家公司內部稽核（由年度覆蓋推導）及管理審查確認狀態；未結 NCR、管理審查先於內稽確認及舊版共用完成標記會提示複核。
- 清單本身依年度共用，存於 AppState `externalAuditPrep`；各列依公司範圍判定完成。舊版旗標和值保留，但不推定為兩家公司皆完成。瀏覽器資料僅供輔助，正式證據仍在組織受控文件系統。

## 資料

- 查檢表種子：`src/data/checklists.seed.json`（`import.finalized: true`）
- 共用題目基準可於「設定」編修，共用受稽核程序文件可於「年度計畫」編修，僅供之後建立的兩家公司表單使用；已建立表單保留當時題目、文件與人員快照，與目前計畫不一致時會提示核對。程序文件仍以組織受控文件為準。
- 同場稽核日期可明確套用另一家公司已填的日期至本表空白欄；兩側已填日期不同時提示核對。共用人員在年度計畫維護，查檢表的人員快照更正收在例外入口。
- 舊版 JSON 若兩份公司計畫在共同欄位或排程有差異，年度計畫頁會逐列要求選擇來源，確認前保留原值並停止新表單建立；確認後原計畫另存於 JSON 的 `legacyCompanyPlanBackup`。
- localStorage：`qms-annual-internal-audit-v7`（可自 v6／v5／v4／v1 遷移）
